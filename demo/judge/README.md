# Warden public judge verifier (synthetic only)

The static judge portal performs real cryptographic verification in the visitor's browser using WebCrypto: pinned manifest and root fingerprint, hash-chain recomputation, Ed25519 approval signatures, X.509 ECDSA signatures and leaf/CSR key equivalence, and DNS SAN scope. It demonstrates a separately generated local evidence package and a separately labeled recorded GCP acceptance report. Those roots/audit heads are intentionally not conflated. A visitor may choose public proof and pin files to independently check a different Warden ceremony, or choose a public three-guest custody-presence report and the independently obtained pins to check its distinct domain-separated signatures. Presence verification does not establish guest location, signing time, independent human operation, or certificate authorization. Files stay in the browser; there is no upload endpoint and no dynamic cloud access.

The recorded cloud report was supplied by the owner after executing the live GCP gate. It records four functioning QBFT validators, two approved distinct TLS endpoints and a transaction confirmed by all four validators. The public portal cannot query that private ledger or demonstrate present uptime, validate a transaction receipt independently from the underlying private chain, or perform custodian/private-CA operations. It also is not an exhaustive general-purpose PKI validator. No HSM equivalence or actual independent human custody is claimed. The live owner demonstration remains separate.

Run `node build.mjs` then `node --test test_verify.mjs test_preview.mjs` with Node 22+. The build generates `dist/worker.mjs`, a static Cloudflare Worker with GET/HEAD only and no bindings, plus `dist/standalone.html`, a self-contained local review artifact. No credentials or account IDs are included. Deploy only to an explicitly owner-authorized competition Worker on the existing Free plan (no paid upgrade), and verify the actual public URL separately. Generated `dist/` should not be committed.
